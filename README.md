# Опрос: дерево в разных стилях

Школьный сайт-эксперимент: одно дерево — **14** визуальных стилей — один и тот же вопрос — обезличенная **общая** статистика.

- **Репозиторий:** [github.com/NeGoriCBT/Polina](https://github.com/NeGoriCBT/Polina)
- **Онлайн (GitHub Pages):** [negoricbt.github.io/Polina](https://negoricbt.github.io/Polina/)
- **Локально:** http://127.0.0.1:3847 после `npm start`

## Как запустить локально

```bash
git clone https://github.com/NeGoriCBT/Polina.git
cd Polina
npm start
```

Откройте в браузере: **http://127.0.0.1:3847**

## Картинки (14 шт.)

Положите файлы в папку `images/`:

| Файл | Подпись |
|------|---------|
| `images/tree-1.png` | Стиль 1 |
| `images/tree-2.png` | Стиль 2 |
| … | … |
| `images/tree-14.png` | Стиль 14 |

Допустимы также `.jpg`, `.jpeg`, `.webp` с теми же именами (`tree-1.jpg` и т.д.).  
Пока файлов нет — на сайте пустые квадраты «Стиль 1»…«Стиль 14».

После замены картинок обновите страницу в браузере.

На **каждой** из 14 картинок один вопрос:

**Что вы чувствуете в первую очередь?**  
спокойствие / тревогу / радость / грусть / ничего особенного

## Как копится статистика

Ответы **без имён**. Схема записи: schema **3** (14 ответов). Старые прохождения с 7 картинками не учитываются.

### На GitHub Pages

Общая сводка для всех посетителей — облако **MantleDB** (`config.js`).  
Новые ответы пишутся в путь `submissions14/…` (старые `submissions/` с 7 ответами игнорируются).

### Локально (`npm start`)

1. Файл `data/submissions.json` через Node API.
2. При настроенном `config.js` — дополнительно в MantleDB (общая сводка с Pages).

Кнопки на вводной: **Далее** (пройти опрос) и **Результаты** (сразу к общей статистике).

## Требования

- Node.js 18+ для локального сервера
- Интернет для шрифтов и облачной статистики на Pages
