# Опрос: дерево в разных стилях

Школьный сайт-эксперимент: одно дерево — семь визуальных стилей — один вопрос к каждой картинке — обезличенная статистика.

- **Репозиторий:** [github.com/NeGoriCBT/Polina](https://github.com/NeGoriCBT/Polina)
- **Онлайн (GitHub Pages):** [negoricbt.github.io/Polina](https://negoricbt.github.io/Polina/)
- **Локально:** http://127.0.0.1:3847 после `npm start`

## Как запустить локально

```bash
git clone https://github.com/NeGoriCBT/Polina.git
cd Polina
npm start
```

Откройте в браузере: **http://127.0.0.1:3847**

Остановить сервер: `Ctrl+C` в Терминале.

## GitHub Pages

Сайт открывается здесь: **https://negoricbt.github.io/Polina/**

На Pages **нет Node-сервера**, поэтому общая статистика для всех участников на сервере не копится.  
В режиме Pages ответы сохраняются в **localStorage этого браузера** (демо).  
Для общей школьной сводки у всех запускайте `npm start` локально — тогда ответы пишутся в `data/submissions.json`.

## Картинки и вопросы

Файлы лежат в `images/`. Каждой картинке соответствует **один** вопрос:

| Файл | Вопрос |
|------|--------|
| `tree-1.png` | Что вы чувствуете в первую очередь? |
| `tree-2.png` | Какое настроение у картинки? |
| `tree-3.png` | Насколько она вам нравится? |
| `tree-4.png` | Кажется ли дерево живым? |
| `tree-5.png` | Где бы вы её представили? |
| `tree-6.png` | Эта картина скорее… |
| `tree-7.png` | Хотели бы вы оказаться рядом с этим деревом? |

После замены картинок обновите страницу в браузере.

## Как устроен опрос

1. **Вводная** — короткое описание и кнопка «Далее».
2. **Опрос** — 7 шагов: квадратная картинка + один вопрос с одним выбором.
3. **Результаты** — все стили и статистика.

## Данные

- Локально (`npm start`): `data/submissions.json` на диске.
- На GitHub Pages: localStorage в браузере (без общего сервера).

## Требования

- Node.js 18+ для локального сервера
- Интернет нужен для шрифтов Google Fonts
