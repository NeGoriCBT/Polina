# Опрос: дерево в разных стилях

Школьный сайт-эксперимент: одно дерево — семь визуальных стилей — один вопрос к каждой картинке — обезличенная статистика.

## Как запустить

```bash
cd ~/Projects/tree-perception-survey
npm start
```

Откройте в браузере: **http://127.0.0.1:3847**

Остановить сервер: `Ctrl+C` в Терминале.

## Картинки и вопросы

Файлы лежат в `images/`. Каждой картинке соответствует **один** вопрос:

| Файл | Вопрос |
|------|--------|
| `tree-1.png` | Что вы чувствуете в первую очередь? |
| `tree-2.png` | Какое настроение у картинки? |
| `tree-3.png` | Насколько она вам нравится? |
| `tree-4.png` | Кажется ли дерево живым? |
| `tree-5.png` | Где бы вы её представили? |
| `tree-6.png` | Эта картина скорее… |
| `tree-7.png` | Хотели бы вы оказаться рядом с этим деревом? |

После замены картинок обновите страницу в браузере.

## Как устроен опрос

1. **Вводная** — короткое описание и кнопка «Далее».
2. **Опрос** — 7 шагов: квадратная картинка + один вопрос с одним выбором.
3. **Результаты** — все стили и общая статистика; ваш ответ отмечен рядом с процентами.

## Данные

Ответы сохраняются без имён и ID в `data/submissions.json`.
Старая схема (5×5 вопросов) сброшена; текущая — schema 2 (один ответ на картинку).

## Требования

- Node.js 18+
- Интернет нужен только для шрифтов Google Fonts; сам опрос работает локально.
