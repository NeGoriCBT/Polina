# Опрос: дерево в разных стилях

Школьный сайт-эксперимент: одно дерево — семь визуальных стилей — один и тот же вопрос — обезличенная **общая** статистика.

- **Репозиторий:** [github.com/NeGoriCBT/Polina](https://github.com/NeGoriCBT/Polina)
- **Онлайн (GitHub Pages):** [negoricbt.github.io/Polina](https://negoricbt.github.io/Polina/)
- **Локально:** http://127.0.0.1:3847 после `npm start`

## Как запустить локально

```bash
git clone https://github.com/NeGoriCBT/Polina.git
cd Polina
npm start
```

Откройте в браузере: **http://127.0.0.1:3847**

Остановить сервер: `Ctrl+C` в Терминале.

## Как копится статистика

Ответы **без имён и ID**. На каждой из 7 картинок один вопрос:

**Что вы чувствуете в первую очередь?**  
спокойствие / тревогу / радость / грусть / ничего особенного

### На GitHub Pages (общий сайт)

GitHub Pages — только статика, своего Node-сервера там нет.  
Поэтому общая сводка для всех посетителей пишется в облако **MantleDB** (бесплатное JSON-хранилище).

- Каждый проход **дописывается** отдельной записью.
- Страница результатов читает все записи и считает проценты.
- Настройки: файл `config.js` (namespace + публичный ключ записи для школьного демо).

Ключ в `config.js` **специально публичный** для школьного эксперимента: сайт должен уметь писать ответы прямо из браузера. Не используйте этот ключ для секретов. При желании можно создать свой namespace на [mantledb.sh](https://mantledb.sh/) и подставить его в `config.js`.

### Локально (`npm start`)

1. Ответы также сохраняются в файл `data/submissions.json` через Node API.
2. Если настроен `config.js`, ответы **дополнительно** уходят в MantleDB — тогда локальный прогон и сайт на Pages видят одну общую облачную сводку.

Если облако недоступно, сайт переходит в резерв: статистика только в этом браузере (localStorage).
