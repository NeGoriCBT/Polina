# Опрос: дерево в разных стилях

Школьный сайт-эксперимент: одно дерево — **16** визуальных стилей — один и тот же вопрос — обезличенная **общая** статистика.

- **Репозиторий:** [github.com/NeGoriCBT/Polina](https://github.com/NeGoriCBT/Polina)
- **Онлайн (GitHub Pages):** [negoricbt.github.io/Polina](https://negoricbt.github.io/Polina/)
- **Локально:** http://127.0.0.1:3847 после `npm start`

## Как запустить локально

```bash
git clone https://github.com/NeGoriCBT/Polina.git
cd Polina
npm start
```

Откройте в браузере: **http://127.0.0.1:3847**

## Как копится статистика

Ответы **без имён**. Схема записи: schema **7** (16 ответов). Старые прохождения не учитываются.

### На GitHub Pages

Общая сводка для всех посетителей — облако **MantleDB** (`config.js`).  
Новые ответы пишутся в путь `submissions16/…` (старые агрегаты не учитываются).

### Локально (`npm start`)

1. Файл `data/submissions.json` через Node API.
2. При настроенном `config.js` — дополнительно в MantleDB (общая сводка с Pages).

Кнопки на вводной: **Далее** (пройти опрос) и **Результаты** (сразу к общей статистике).

## Требования

- Node.js 18+ для локального сервера
- Интернет для шрифтов и облачной статистики на Pages
